# COMP 1238 Notes

## Week 1 - Information Storage Before Computers
- People used writing systems, such as cuneiform, to record and preserve information.
- Libraries and physical documents helped people organize and share knowledge before computers.

## Week 2 - Representing Text and Numbers in Computers
- Computers store information using bits, which have the values 0 or 1.
- Character encoding systems represent text as numbers so computers can store and process it.

## Week 3 - Markup Languages
- Markdown uses simple symbols to format text, such as `#` for headings and `-` for bullet points.
- Links in Markdown use this format: `[link text](URL)`.

## Week 4 - Keyboards & Editors
- Keyboard shortcuts can make editing text faster.
- A text editor lets you create and edit plain text files, including Markdown files.

## Week 5 - CLI
- A command-line interface lets users interact with a computer by entering text commands.
- Commands can be used to navigate folders, list files, and create or edit files.

## Week 6 - Versioning
- Git records changes to files over time so you can review earlier versions.
- A commit saves a set of changes with a message describing what changed.
